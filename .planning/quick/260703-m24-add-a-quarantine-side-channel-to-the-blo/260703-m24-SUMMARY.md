# Phase 260703-m24 Plan 01: Add a quarantine side-channel to the bloom plugin Summary

Ported the router plugin's proven quarantine side-channel onto the `bloom` writePolicy plugin by reusing the checker-agnostic `RouterHandler` + `RouterIOAdapter` over the existing `BloomChecker`, so not-in-set kind-0/1/3 events are forwarded fire-and-forget to the quarantine relay while the mainline reject decision and zero-per-event-HTTP hot path stay byte-identical.

## What Was Built

- **Task 1 (feat, `ee52bef`)** — Added a `Quarantine QuarantineConfig` field (reusing the router's type) to `BloomConfig` and the same five quarantine defaults (`enabled=true`, `relay_url=ws://strfry-quarantine:7778`, `buffer_size=10000`, `publish_timeout=5s`, `metrics_interval=60s`) to `LoadBloomConfig`. No env-prefix was added, keeping the loader shape identical to legacy. Two new table tests cover defaults + override (including `enabled=false`) and assert the existing `bloom_` defaults are untouched by the nested section.
- **Task 2 (feat, `40c246c`)** — Rewired `cmd/bloom/main.go`: kept the `BloomChecker`/`BloomFetcher` construction (fetcher remains the sole filter writer), replaced `WhitelistHandler`+`JSONLIOAdapter` with `NewRouterHandler(checker, publisher, cfg.Quarantine.Enabled, logger)` + `NewRouterIOAdapter`, and constructed/started/stopped the `quarantine.Publisher` from `cfg.Quarantine` exactly as `cmd/router` does (guarded `publisher.Stop(2s)` on error-exit and normal return). The event-loop/processLine/safeOutput signatures were switched to the router-style `routerHandler`/`routerIO` interfaces. `make build-bloom` produces `bin/bloom`; `go vet ./cmd/bloom/` is clean.
- **Task 3 (test, `d8ec4b0`)** — Added `pkg/bloomgate/router_quarantine_test.go` (external `bloomgate_test` package to avoid the `handler -> bloomgate` import cycle) proving `RouterHandler` is genuinely checker-agnostic on the bloom path: a real `BloomChecker` backed by a filter containing a known pubkey yields accept + no enqueue for the in-set pubkey and reject + fire-and-forget enqueue for an out-of-set kind-1 pubkey. Documented the side-channel and the nested `quarantine:` config in the README's Bloom Gate Plugin section, referencing the router section for shared invariants.
