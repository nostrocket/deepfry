<objective>
Lower `heuristics.MaxContentBytes` from `256 * 1024` (256 KB) to `65536` (64 KB) so the pre-quarantine garbage gate drops oversized events BEFORE they are forwarded, aligning the gate to the quarantine relay's `maxEventSize = 65536`.

Purpose: The live bloom quarantine side-channel (quick task 260703-m24) shows heavy reconnect churn. The quarantine relay rejects any event whose total serialized size exceeds 64 KB and closes the WebSocket (1006), forcing the fire-and-forget publisher to reconnect. Because the current gate allows `evt.Content` up to 256 KB, events with 64 KB–256 KB content pass the gate, get forwarded, then get rejected by the relay as "event too large" — one 100+ KB event was observed triggering several consecutive reconnects. Dropping those at the gate eliminates the bulk of that churn.

Output: Updated constant + doc comment in `whitelist-plugin/pkg/heuristics/heuristics.go`.
</objective>
